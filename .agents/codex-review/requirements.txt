基于 Element Plus（按需加载）完成前端 UI 组件升级，具体要求与验收条件：
1. 架构与规范约束：
   - 严格保持零 TypeScript 策略（0 个 .ts/.tsx/.mts/.cts/tsconfig），所有源码与配置均为纯 JS/Vue 3 SFC。
   - 按需加载 Element Plus（`element-plus` + `@element-plus/icons-vue` + `unplugin-element-plus/vite`），不引入全量 CSS 膨胀包体；Vitest 测试环境内联支持 `element-plus`。
   - 在 App 根部接入 `ElConfigProvider`（简体中文语言包 `zh-cn`）及 `ElMessage` 全局提示；卸载时清理残留弹窗/消息。
2. 双主题无缝联动与现代暗黑模式：
   - `applyTheme()` 及所有 HTML 入口首屏内联脚本同步维护 `data-theme` 与 `html.dark`（适配 Element Plus 暗黑模式），并声明 `<meta name="color-scheme" content="light dark" />` 防 FOUC。
   - 在 `element-theme.css` 中将 Element Plus CSS 变量（`--el-*`）完整映射到项目现有的浅色/深色设计令牌，避免风格割裂。
3. 全站 UI 组件升级：
   - 封装统一的 `RadarSelect.vue`（基于 `ElSelect` + `ElOption`，支持可搜索、地区/店铺徽标与计数、筛选高亮态），替换全站所有原生 `<select>`（FilterDock 桌面/移动端、ProvidersView、RadarView）。
   - 搜索输入与全局命令面板输入框升级为 `ElInput`（配图标与清空）；桌面列表/卡片切换及大盘时间窗口（`24h`/`72h`/`7天`）升级为 `ElSegmented`（保留窄屏 `<=860px` 隐藏 `.layout-view-toggle` 且保留 `.radar-window-toggle` 可见可点）；移动端红线与差异高亮/收藏过滤升级为 `ElSwitch`。
   - 详情抽屉、收藏抽屉升级为 `ElDrawer`，横向对比弹窗与命令面板升级为 `ElDialog`，状态横幅升级为 `ElAlert`，避坑自检进度条升级为 `ElProgress`，加载态/空状态/标签/核心按钮升级为 `ElSkeleton`/`ElEmpty`/`ElTag`/`ElButton`。
   - 抽屉/弹窗关闭时彻底释放焦点陷阱，不影响 `[data-tag-hud]` 键盘聚焦、视口防越界、零 XSS 及原有业务筛选/对比/收藏/URL 同步/回滚/3,700+ 行 `@tanstack/vue-virtual` 虚拟滚动（DOM 节点受控 < 4,000）。
4. 验证与回归：
   - `npm run check`、`npm test`（含 Node 单测、Vitest 前端单测与 Playwright 真实浏览器 E2E）及 `npm run monitor:validate` 全部通过。
