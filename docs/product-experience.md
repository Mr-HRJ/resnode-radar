# VPS 节点雷达：产品与交互说明

## 页面与主要流程

网站沿用静态前端 + 定时采集 + Cloudflare Workers 的架构。首页参考 PriceAI 的浅色留白、标签筛选和价格层级，结合 VPS 帮帮车的配置与库存信息密度；使用独立的灰绿视觉体系、本地 SVG 图标和系统字体。

| 页面 | 使用方式 |
| --- | --- |
| 套餐探索 | 先选普通 VPS / 住宅类别，再按地区、线路、厂商、IP、币种、计费周期和库存筛选；支持搜索厂商别名与规格、分页、表格 / 卡片切换。 |
| 商家导航 | 查看所有收录厂商，按地区和采集状态筛选；“采集详情”显示来源及访问限制，“查看套餐”跳到该厂商的产品。 |
| 库存动态 | 查看相邻采集轮次之间恢复可订购、变为不可订购及标价变化；可按事件类型筛选。 |
| 选购指南 | 解释用途、线路、计费与库存证据；含线路速查表和常见问题。 |

所有套餐保留官网入口和原始来源。桌面表格与手机卡片共用同一套筛选结果和选择状态。产品详情保留原始配置、账单、采集时间、证据与注意事项；精简配置只用于列表阅读。

## 收藏与比较

- 书签将套餐身份保存在当前浏览器；价格变化、排序和重新读取数据不移除收藏。
- “我的收藏”清除其他条件后进入收藏列表，“只看收藏”可与当前条件叠加。
- 本轮未采集到的收藏仍保留在浏览器，但不显示为当前套餐。
- 可以跨页、跨筛选选择最多四个方案；选择两个后可打开参数对比。
- 对比表逐行展示差异，保留原币种及支付周期；手机可在弹窗内部横向查看。
- 收藏不会发送邮件、Telegram 或浏览器推送，也不跨设备同步。浏览器禁止存储时，本次访问中的收藏仍可使用，并显示提示。

## 时间、价格与证据

后台每 30 分钟计划运行一次，可能有调度延迟。前台页面可见时每 5 分钟重新读取已发布的数据；手动刷新具有相同行为。顶部显示实际采集时间，超过 90 分钟出现过期提示。时间按浏览器本地时区显示。

库存的“可订购”可能来自明确数量、官方可用标志或可下单入口，列表会显示对应依据。数量未公开时不推算余量，访问受限不等同售罄。只有可订购且具有明确正数库存的套餐计入“明确库存方案”。

`data/products.json` 的新增字段：

| 字段 | 含义 |
| --- | --- |
| `events` | 已观测的 `restock`、`soldout`、`price` 事件数组，首次建立基线为空。 |
| `eventTracking` | 开始时间、7 天保留期与 300 条上限。 |
| `exchangeRates` | 可选，ECB 原始日期、来源和以人民币为基准重新计算的汇率。 |

采集器比较身份明确的相邻观测。新收录的商家、消失的产品、访问失败、未知状态和第三方快照不制造补货 / 售罄事件。价格事件要求币种、周期与方案保持可比。事件记录“发现时间”，不声称是商家实际变更瞬间。

原始报价始终优先展示。折合月价不表示商家支持月付。仅已知币种、明确周期且非可选配置的起步价格参与参考换算。ECB 汇率使用公开来源和实际日期；超过七天的外币汇率不再用于换算。税费、银行卡汇差、安装费及续费条件由用户在官网核对。

## 浏览、键盘与状态

筛选和页面视图编码到 URL，可复制分享；浏览器返回可以恢复页面视图。`/` 聚焦搜索框，`Esc` 关闭原生弹窗。所有主要操作提供按钮名称、焦点轮廓和非纯颜色状态；系统要求减少动态效果时禁用动画。

页面包含加载、无匹配、空收藏、动态基线、采集过期和接口失败状态。接口失败时清空当前产品与可用数量，显示“库存未知”，不会把旧结果冒充为最新库存。并发刷新只接受最新请求的结果。

## 运行与检查

```sh
npm ci
npm run serve
# http://127.0.0.1:4173/

npm run check
npm test
npm run monitor:validate
npm run build:cloudflare
```

更新汇率和供应商数据：

```sh
npm run fx:update
npm run monitor
npm run monitor:validate
```

仅在需要更新采集结果时运行 `monitor`。页面调试可以直接使用已有 JSON；开发与测试不需要每次请求所有供应商。
