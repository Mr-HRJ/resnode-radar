# ResNode Radar：零基产品与交互架构说明

## 1. 核心定位与四维工作区

ResNode Radar v2 采用纯原生 JavaScript（零 TypeScript）`npm workspaces` 全栈架构：**Vue 3.5 + Vite 6 + `@tanstack/vue-virtual` 前端工作台（`apps/web`）+ Zod 共享契约与紧凑快照投射（`packages/contracts`）+ 20 分钟级多源采集与四阶段原子发布器（`apps/collector`）+ Worker 线程隔离脉冲/访问统计服务（`apps/server`）**，打造面向跨境业务运营者、独立开发者与基础设施玩家的**首屏即工作台（Zero-Hero Intelligence Terminal）**。

| 工作区视图 | 核心决策职责与交互能力 |
| :--- | :--- |
| **选品工作台 (`workbench`)** | 默认首屏。集成实时变盘速报条、五大本质场景透镜（全部可售 / 真家宽·双ISP / 回国优化线路 / 机房原生·常规落地 / 高配算力·大盘鸡）、正交多维复合筛选、桌面端高密度等宽数据矩阵 / 紧凑卡片双视图、移动端三段式战术卡片，以及 **0 结果智能冲突归因引擎**。 |
| **异动雷达 (`radar`)** | 汇总近 7 日滚动窗口（最多 300 条）内经相邻有效观测确认的补货上架（Restock）、售罄下架（Soldout）与同币种同周期调价（Price Δ，自动计算涨跌幅百分比），支持「仅看收藏套餐及所属商家」过滤。 |
| **商家档案库 (`directory`)** | 收录 121 家去重厂商元数据（覆盖 MeowVPS 全部 117 家含收集中商家 + 本站自有监控源）与实时可观测性健康度，可视化呈现精确库存 / 官方订购入口 / 售罄 / 异常比例微条，承载 `diagnostic: true` 采集诊断日志、`collection.pageLimitReached` 目录翻页上限预警及独立实测记录入口。 |
| **核验手册 (`manual`)** | 内置四大常见选型场景一键跳转预设、真假家宽与双 ISP 四步验真法（ASN/WHOIS/BGP）、回国线路等级对照矩阵（CN2 GIA / 9929 / CMIN2 / 4837 / IIJ / 软银）以及计费文字游戏拆解指南。 |

独立厂商实测子页（`reviews/aaitr.html`、`reviews/lisahost.html`）与主站共享同一套语义化 Design System（`styles/tokens.css`、`styles/base.css`、`styles/workbench.css`、`styles/content-pages.css`），并通过 `src/review-hydration.js` 实时水合最新监控库存快照；未补齐一手实测截图前严格保留 `noindex` 与草稿诚实性声明，绝不展示虚构评分或样本延迟。

## 2. 本质分类、价格诚实度与证据边界

- **真家宽 / 双 ISP 与机房原生 IP 严格分流**：`src/data/classify.js` 仅依据采集记录客观声明字段判定属性。仅声明「原生 IP」而无住宅宽带/本土 ISP 宿主特征的普通机房实例显式标注为 `机房原生IP`，绝不混入「真家宽 / 双 ISP」透镜；含 `nat-shared` 或声明共享端口的方案显式标记 `NAT共享`，支持一键排除。
- **供货状态与证据等级双轨呈现**：区分 `精确库存 N`（官方返回明确正整数余量）、`订购入口`（仅验证下单入口可达，未公开余量）、`快照有货`（第三方 Reader 缓存回退，非一手实时直连）、`已售罄`、`待核验` 与 `直连受阻`（验证盾或登录拦截绝不等同于缺货）。
- **原币种优先与 ECB 汇率 7 天熔断**：始终首行展示商家原始账单字符串；仅对周期明确可折算自然月且非「起步价 / 可选配（`baseOnly`）」的固定套餐计算月均参考值。外币折算人民币月均严格校验欧洲央行（ECB）汇率日期是否在 **7 天有效期内**，超期自动停止外币换算并给出显式提示。
- **商家标签客观分口径核验（7 维体系：热门顶流 / 老牌稳健 / 原生家宽 / 回国优线 / 大口高配 / 高性价比 / 低价入门）**：
  - `热门`（热门顶流）：由 `src/domain/catalog.js` 显式维护业内长期高关注的主流代表品牌清单（如搬瓦工、DMIT、Gomami、VMISS、V.PS、LisaHost、Misaka、绿云、斯巴达、ZgoCloud、咸鱼云、花卷、ISIF、车库云），绝不以套餐 SKU 条数判定热门程度。
  - `老牌`（老牌稳健）：限定多年持续稳定运营、账单与履约记录成熟的老牌主机商（如搬瓦工、绿云、斯巴达、netcup、HostDare、BuyVM、HostHatch、RackNerd、MoonVM、Evoxt）。
  - `家宽`（原生家宽）：基于在售独立 IP 且显式标注住宅/双 ISP/本土宽带运营商的现货占比（≥4 款且占全店在售 ≥40%，或 ≥20 款且占比 ≥35%）及已核验专营商家档案判定，自动剔除普通机房 BGP 混标与纯 NAT 方案。
  - `优线`（回国优线）：基于在售非 NAT 大陆直连优化（CN2 GIA / 9929 / CMIN2 / 三网精品 / 软银 / IIJ）现货占比（≥4 款且占全店在售 ≥45%，或 ≥12 款三网/GIA 且占比 ≥40%）及专营老牌档案判定，剔除 10–20Mbps 小水管凑数目录。
  - `高配`（大口高配）：实测在售 ≥6 款且占全店在售 ≥44% 为 ≥2.5Gbps/10Gbps 大带宽端口或 AMD Ryzen / EPYC 高性能硬件方案（剔除内地机房）。
  - `性价比`（高性价比）：严格要求当前合格明码在售报价支撑（绝不对无在售套餐或汇率超期的商家做品牌兜底），基于完整非 NAT 有效目录分母与全店真实中位价（`catalogMedCny`）校验高配置比占比（≥25% 或中位 ≤￥65）、平价 CN 优化占比或全店多档低中位价，彻底杜绝大目录仅靠少量低价款冒充全店高性价比。
  - `低价`（低价入门）：严格要求当前合格明码在售报价支撑，基于完整非 NAT 有效目录分母校验存在月均 ≤ ￥15/月（且全店中位价 ≤ ￥65 或 ≤￥20 占比 ≥25%）或 ≥ 4 款 ≤ ￥20/月（占比 ≥15% 且全店 P25 ≤ ￥35）的低门槛现货。
  - 严格统一排除 **NAT 共享端口**、内地机房、起步价（`baseOnly`）、未知计费周期与超期汇率记录；不符合真实依据的商家保持中性无标签。全部店铺与单品徽章均配备前置定制矢量动态图标（如 `热门`/`爆款` 双层火焰跳动与流光扫掠、`紧俏` 声呐脉冲、`高配` 闪电呼吸、`年付惠` 星芒闪烁，并完整适配 `prefers-reduced-motion`）、鼠标悬停与键盘聚焦双通路可访问核验浮窗（HUD，`role="tooltip"` + `aria-describedby`）及一键点击同标签筛选联动。
- **单品亮点标签客观分口径核验（8 维体系：口碑爆款 / 便宜量大 / 年付特惠 / 高性价比 / 家宽直连 / 性能高配 / 紧俏余量 / 低价入门）**：
  - 全部单品标签仅作用于**当前在售（`available`）、非 NAT / 非共享端口、跨境/海外节点（剔除内地机房）、明码固定周期且 ECB 汇率在 7 天有效期内**的真实商品，支持工作台一键筛选与 `?deal=` 链接分享，详情抽屉与横向对比同步披露每条标签的实测依据：
  - `爆款`（口碑爆款）：严格限定业内公认稀缺传家宝与头部商家标志性特惠型号（如搬瓦工 `bwh-limited-pids` 限量系列、LisaHost 经典特价年付双 ISP/三网款、AkkoCloud CN2 年付特惠、六六云美西双 ISP 9929、破云 GGBOOM 年付特价等），绝不对常规高溢价目录款或全店套餐无差别打标。
  - `便宜量大`：必须已核验明确端口带宽（拒绝未知带宽盲盒与小水管），满足月均 ≤ ￥35 伴 ≥100Mbps 不限流量 / ≥200Mbps 且 ≥3TB 大流量 / ≥2核4G30G 大内存高配，或 ≤ ￥45 伴 ≥100G 真大盘存储。
  - `年付惠`（年付特惠）：明码年付或更长固定周期、内存 ≥1G、已核验 ≥500G/不限流量，且折合月均 ≤ ￥24/月（≥800G 大流量常规款）或 ≤ ￥48/月（CN 优化或真家宽），剔除 512M 小内存与低流量套路年付。
  - `性价比`（高性价比）：要求内存、≥100Mbps 端口带宽与流量配额三项齐备核验，满足平价 CN 回国优化（常规 ≤￥36/月，三网/GIA/9929/CMIN2 ≤￥48/月）、平价真家宽/双 ISP（≤￥55/月），或 ≥2核4G25G、≥200Mbps、月均 ≤￥65 且每 ￥10/月 ≥1.0G 内存的高配置比方案，彻底剔除 10–50Mbps 小水管。
  - `家宽直连`：明码固定周期（月均 ≤￥220，排除 `起` 字选配价与周期未明款）、显式住宅/双 ISP 标记且叠加 CN 回国优化线路（排除误归类的 E5 独服/物理机与共享端口），跨境免中转一步到位。
  - `高配`（性能高配）：硬件底线严格要求 **≥2核且 ≥4G 内存**（绝不将 1核1G/1核2G 万兆共享口入门机标为高配），需标明 AMD Ryzen / EPYC / Xeon Gold·Platinum 处理器（≤￥85/月），或达到 ≥4核8G40G + ≥500Mbps 大带宽（≤￥75/月）。
  - `紧俏`（紧俏余量）：监控精确核验仅剩 1–5 台正整数库存，且满足 ≥1G 内存、≥100Mbps 端口、已核验流量配额与主流消费级预算上限（常规 ≤￥60/月，真家宽/HKT ≤￥160/月），剔除玩具容器与高价大切片机型。
  - `低价`（低价入门）：明码固定周期折合月均 ≤ ￥18/月，且核验具备 ≥512M 内存、≥10G 硬盘、≥500G/不限流量及非小水管端口的可用低门槛现货。
- **快照新鲜度与四态诚实降级**：页面可见时每 5 分钟通过 `/api/v1/pulse`（约 300B）轮询快照版本，版本未变时零流量跳过下载，变更时读取不可变 `data/snapshots/<snapshotId>/snapshot.json`（打开套餐详情抽屉时再按需懒加载 `audit/<sourceId>.json` 原始 HTTP 尝试记录）。采集器每 **20 分钟**运行一次，快照生成时间超过 **30 分钟**标记琥珀色陈旧预警；首次加载失败展示诚实不可用空态，后台轮询失败则保留上一份已验证快照并弹出顶部同步告警横幅，绝不伪造零库存或回退模拟数据。

## 3. 核验抽屉、横向对比、收藏与全状态 URL

- **右侧滑出核验抽屉（Slide-Over Inspector）**：点击任意套餐或商家即可原地滑出抽屉，查阅账单拆解、硬件参数、亮点标签核验依据、按需分片加载的源站 HTTP 尝试与近期连续巡检记录及同商家近期异动；支持 `Esc` 键与遮罩点击关闭并恢复触发焦点。
- **多方案横向对比矩阵（Compare Workbench）**：支持跨筛选勾选最多 4 款方案并排比对，内置「仅展示有差异的指标行」开关及最优库存确定性 / 最低参考月均提示。
- **全状态 URL 同步**：视图、透镜、筛选词、排序、对比池标识（`?cmp=<savedKey>`）与当前核验对象（`?inspect=<productId>`）均实时同步至 URL Query，支持一键复制分享完整上下文链接及浏览器前进/后退恢复。

## 4. 本地验证与构建命令

```sh
npm run check            # 零 TS 检查 + 全工作区 JS/MJS 语法 + Vue SFC 编译与兼容垫片校验
npm test                 # 运行 contracts / collector / server / scripts 与 apps/web Vitest 全部测试
npm run test:e2e         # 运行 Playwright Headless Chrome 桌面/移动/虚拟滚动/实时回滚端到端验证
npm run monitor:validate # 校验 data/products.json 与 data/v2 分片快照双向无损等价契约
npm run build:vps        # 构建生产不可变版本化前端产物至 dist/
npm run serve            # 启动本地静态与脉冲预览服务 http://127.0.0.1:4173/
```
